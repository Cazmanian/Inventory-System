--------------------------- INVENTORY SYSTEM --------------------------------

Created an Inventory system based off of a GUI mockup and UML diagram provided

[GUI Mock up.docx](https://github.com/user-attachments/files/32346118/GUI.Mock.up.docx)

[UML Class Diagram (1).pdf](https://github.com/user-attachments/files/32346129/UML.Class.Diagram.1.pdf)


Main Form:
Add parts, products, search for parts and products

Add Products form: 
Add products, modify, delete and search for products
When creating a product you can associate a part with that product


Add Parts form:
Add parts, modify, delete and search for parts.
Part can be In-house or outsourced
